# InsightChat 记忆系统手工测试脚本

> 用途：通过真实页面操作，完整验证短期记忆、长期偏好、个人问答对、用户隔离、遗忘与异常分支。
> 使用方式：按章节顺序执行；代码块中的内容可直接复制到对话输入框。
> 涉及点击操作时，会明确写出“新会话”“点赞”“重启服务”等步骤，其余均为对话测试问题。

## 1. 测试准备

### 1.1 测试账号

| 账号 | 用途 |
|---|---|
| `analyst` | 主测试账号，验证记忆写入、读取、跨会话继承与管理 |
| `east_mgr` | 第二账号，验证用户之间的记忆隔离 |

### 1.2 每轮测试前清理

```text
忘掉全部记忆
```

预期结果：

- 长期记忆被清除；
- 当前会话上下文被重置；
- 历史消息与审计记录保留。

### 1.3 操作约定

- “新开对话”均指点击页面上的“新会话”，不是在原会话中继续追问。
- 需要验证跨会话继承时，必须先完成记忆写入，再新开对话提问。
- 除特别说明外，每步都应检查页面回答、假设区以及“记忆使用”留痕。

---

## 2. 对话切图并跨会话记住图表偏好

### 步骤

1. 输入：

   ```text
   2024年3月到5月每月净销售额
   ```

   预期：默认展示折线图。

2. 在同一对话中输入：

   ```text
   换成柱状图
   ```

   预期：

   - 无需重新查询数据，当前结果切为柱状图；
   - 提示已记住趋势分析场景的图表偏好；
   - “记忆使用”留痕同步更新。

3. 点击“新会话”，再次输入：

   ```text
   2024年3月到5月每月净销售额
   ```

   预期：

   - 自动使用柱状图；
   - 假设区或“记忆使用”中说明沿用了图表偏好。

4. 输入：

   ```text
   你记得我什么
   ```

   预期：能看到“趋势分析 → 柱状图”。

5. 输入：

   ```text
   忘掉图表偏好
   ```

   预期：提示图表偏好已删除。

6. 新开对话，再次输入：

   ```text
   2024年3月到5月每月净销售额
   ```

   预期：恢复默认折线图。

## 3. 明确指定长期图表偏好

依次输入：

```text
以后趋势都用折线图
```

预期：提示已记住趋势分析场景偏好折线图。

```text
以后分类对比都用柱状图
```

预期：提示已记住分类对比场景偏好柱状图。

```text
以后占比分析都用饼图
```

预期：提示已记住占比分析场景偏好饼图。

然后输入：

```text
查看我的记忆
```

预期：列出上述三类偏好。

也可以打开右上角“记忆”，检查：

- 记忆内容与数据场景；
- 来源；
- 有效置信度；
- 生效状态；
- 使用次数。

先清理：


输入：

```text
2024年3月到5月每月净销售额，用柱状图展示
```

预期：

- 本次使用柱状图；
- 留痕注明“未写入长期偏好”。

新开对话，输入：

```text
2024年3月到5月每月净销售额
```

预期：恢复默认折线图，证明前一次仅影响当次结果，没有形成长期偏好。

## 5. 否定表达与普通“表格”文本不应误判

### 5.1 否定图型

```text
2024年4月各大区的净销售额，不要用饼图
```

预期：正常查询并使用默认柱状图，不能强制切成饼图。

```text
2024年3月到5月每月净销售额，别再用折线图了
```

预期：不能出现“按您当次要求使用折线图”的留痕。

### 5.2 普通文本中的“表格”

```text
这个表格里的数据是什么意思
```

预期：可以进入闲聊或不可回答分支，但不能被当成“输出为表格”的图表指令。

## 6. 无图切换与不兼容图型

### 6.1 尚未查询时切图

新开对话，直接输入：

```text
换成折线图
```

预期：提示“还没有可切换的图表，请先完成一次数据查询”。

### 6.2 当前数据不支持目标图型

先输入：

```text
2024年4月各大区的净销售额
```

预期：得到分类对比柱状图。

再输入：

```text
换成折线图
```

预期：

- 提示当前数据不支持折线图，并列出可选类型；
- 当前数据与原图表保持可用；
- 不生成错误的长期图表偏好。

## 7. 长期指标口径记忆

先清理：

```text
忘掉全部记忆
```

输入：

```text
记住销售额指净销售额
```

预期：提示已记住“销售额”按“净销售额”查询。

新开对话，输入：

```text
2024年5月华东区的销售额是多少
```

预期：

- 不再弹出“净销售额/毛销售额”澄清卡；
- 留痕显示沿用长期口径偏好；
- SemQL 使用 `metric_net_sales`；
- 结果约为 **140742.24 元**。

继续输入：

```text
2024年5月华东区的毛销售额是多少
```

预期：仍按毛销售额查询，不被长期偏好错误覆盖。

然后输入：

```text
忘掉销售额口径
```

新开对话，再次输入：

```text
2024年5月华东区的销售额是多少
```

预期：重新出现净/毛销售额澄清卡。

## 8. 同一澄清选择跨三个会话自动晋升

> 每一轮都必须点击“新会话”，不能在同一会话内重复。

### 第一个新会话

输入：

```text
四月的销售额怎么样
```

出现澄清卡后选择“净销售额”。

### 第二个新会话

再次输入：

```text
四月的销售额怎么样
```

出现澄清卡后再次选择“净销售额”。

### 第三个新会话

再次输入：

```text
四月的销售额怎么样
```

出现澄清卡后再次选择“净销售额”。

预期：

- 第三次完成后，候选记忆晋升为长期偏好；
- 留痕提示已根据多个会话中的一致选择形成长期偏好。

### 第四个新会话

再次输入：

```text
四月的销售额怎么样
```

预期：不再弹澄清卡，直接按净销售额查询。

补充检查：在同一会话内重复选择，不能刷晋升次数。

然后重启服务，保持当前会话，继续输入：

- 时间仍为 `2024-04-01` 至 `2024-04-30`；
- 区域过滤为 `HB`；
- 结果约为 **117719.74 元**；
- 不需要重新选择指标或时间。

继续验证会话内口径衔接：

```text
记住销售额指净销售额
```

```text
那华北呢
```

预期：继续沿用净销售额，不重复询问净/毛口径。

## 12. 异常与防误判

### 12.1 缺少数据场景

```text
以后都用折线图
```

预期：提示需要说明数据场景，例如趋势或分类对比，而不是盲目保存全局偏好。

### 12.2 不存在的指标

```text
记住销售额指不存在的指标
```

预期：提示找不到唯一指标，不写入记忆。

### 12.3 “以后/今后”开头的普通问题

```text
以后每个月的净销售额是多少
```

```text
今后各月的销量趋势
```

预期：按普通数据问题处理，不能被记忆命令拦截。

## 13. 记忆管理页面

在完成若干图表与口径偏好后，打开右上角“记忆”，逐项检查：

- 加载态正常，不出现空白弹窗；
- 记忆标题、来源、有效置信度、使用次数和状态正确；
- 候选记忆显示“待跨会话确认”；
- 衰减记忆显示“已衰减 · 不生效”；
- 点击单条删除后，只删除目标记忆；
- 删除失败时显示错误，不清空其他记忆；
- 点击“清空长期记忆”并确认后，列表进入空态；
- 无记忆时显示空态提示，接口失败时显示错误与重试入口。

最后执行：

```text
忘掉全部记忆
```

再输入：

```text
你记得我什么
```

预期：提示当前没有记住偏好，测试环境恢复干净。

## 14. 快速验收清单

| 能力 | 通过标志 |
|---|---|
| 对话切图 | 不重新执行 SQL，当前图表即时切换 |
| 图表长期偏好 | 新会话同族查询自动沿用，其他用户不继承 |
| 当次图型指定 | 不写长期记忆，新会话恢复默认 |
| 否定表达 | 不会反向强制成用户明确不要的图型 |
| 长期口径 | “销售额”不再重复澄清，SemQL 使用所选指标 |
| 澄清晋升 | 3 个不同会话一致选择后晋升，同会话不累计 |
| 短期恢复 | 重启后“那华北呢”仍继承时间与指标 |
| 个人问答对 | 点赞后召回，点踩后撤销，用户之间隔离 |
| 用户管理 | 可查看、逐条删除、分类遗忘和全部清空 |
| 异常处理 | 无图切图、非法图型、未知指标均有明确提示 |
| 防误判 | 普通“以后/今后”和“表格”文本不被记忆命令劫持 |
